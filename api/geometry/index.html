Bramble.box

source 
box(a::Number, b::Number) -> CartesianProduct{1, T}
box(a::Tuple{Vararg{Number, D}}, b::Tuple{Vararg{Number, D}}) -> CartesianProduct{D, T}

Construct a CartesianProduct from two opposing corner points a and b.

The corners may mix element types: every coordinate is floated and all axes are promoted to one type T, so box((0.0f0, 0.0), (1.0f0, 0.1)) is a CartesianProduct{2, Float64}. Homogeneous corners keep their type.

Interval bounds for each dimension i are defined by \([\min(a_i, b_i), \max(a_i, b_i)]\).

×(W₁::AbstractSpaceType, W₂::AbstractSpaceType) -> CompositeGridSpace

Construct the Cartesian product space of W₁ and W₂.

Chaining products associatively flattens them into a flat CompositeGridSpace{N}, matching mathematical product space conventions (e.g. W₁ × W₂ × W₃ -> CompositeGridSpace{3}). To explicitly construct hierarchical (nested) composite spaces, call CompositeGridSpace directly (e.g. CompositeGridSpace(Vh, Qh)).

Ghost spaces (GhostGridSpace) combine with ghost spaces only, C₁ × C₂, into a flat composite whose closure is block diagonal over the components; a product with a plain space refuses with an ArgumentError, and a nested composite with a ghost component is refused where it is used (assembly/ghost_composite.jl).

×(C₁::GhostGridSpace, C₂::GhostGridSpace) -> CompositeGridSpace

The composite of two ghost spaces, flat as for plain spaces: C₁ × C₂ × C₃ has three components. Its degrees of freedom are those of C₁ then those of C₂, and its closure is block diagonal, each component constrained by its own relations, so forms on it assemble a vector problem with per-component relations (see GhostGridSpace). Relations coupling the components, such as a traction, are given on the product of the unconstrained ghost spaces, constrained(C₁ × C₂, relations), whose closure is solved for all of them at once. Bramble.padded_space and Bramble.closure give the padded composite and the closure, and lift the padded grid functions of a solution.

A ghost space and a plain one do not combine: the product refuses with an ArgumentError. Forms couple the components only when they ghost the same facets of meshes of one size.

Markers and domains#

Bramble.markers

source 
markers(space_set::CartesianProduct, pairs::Pair...) -> DomainMarkers
markers(space_set::CartesianProduct, time_set::CartesianProduct{1}, pairs::Pair...) -> DomainMarkers

Construct a DomainMarkers collection from label => identifier pairs.

Arguments

  • space_set: Geometric spatial set.

  • time_set: Optional 1D temporal interval for time-dependent boundary conditions. With it, every predicate Function takes (x, t). markers(...)(t) fixes (x, t) predicates at t and keeps spatial x predicates, so it also applies to markers built without it.

  • pairs: Vararg sequence of label => identifier pairs where identifier is a Symbol, a tuple (NTuple{N, Symbol}), AbstractVector{Symbol} or AbstractSet{Symbol} of boundary symbols, a predicate Function (x -> Bool, or (x, t) -> Bool with time_set), or, on a 2D space_set, a Polygon built by polygon or a LevelSet built by levelset (whose φ takes x alone, with or without time_set). A pair :L => polygon(V) gives a mesh the labels L, L_boundary and L_exterior: the nodes inside the polygon, on its boundary and outside it. A node is on the boundary when its distance to the boundary is at most \(\max(\sqrt{\varepsilon} h_{\min}, 10^3 \varepsilon L) + 4 \varepsilon M\), with \(h_{\min}\) the smallest mesh spacing, \(L\) the polygon's extent, \(M\) the largest coordinate magnitude of the polygon's vertices, and \(\varepsilon\) the larger machine epsilon of the mesh's points and the polygon's vertices. A pair :L => levelset(φ) gives the same three labels, with φ < 0 inside.

Throws

  • ArgumentError: if an identifier is of any other kind (for example a String, a Dict or a callable object that is not a Function), names a symbol that is not a boundary of space_set, or, with time_set, is a predicate that does not accept (x, t). Also if a polygon marks a set that is not 2D, has a vertex outside space_set, is labelled :boundary or :interior, or one of its three labels is another marker's. Likewise for a level set, whose φ must also return a Real that is not a Bool at the centre of space_set.

Examples

using Bramble
I = interval(0.0, 1.0)
m = markers(I, :left_boundary => :left, :internal => x -> 0.2 < x < 0.8)
length(symbols(m)) == 1 && length(conditions(m)) == 1

# output
true
markers(Ω::Domain) -> DomainMarkers

Return the DomainMarkers collection associated with domain Ω.

markers(Ωₕ::AbstractMeshType) -> MeshMarkers

Return the MeshMarkers dictionary associated with mesh Ωₕ.

The dictionary and its BitVectors are read-only views of the mesh's labels. Change labels with markers! or set_markers!, which update the marker state assembly reads; an edit made in place is not seen by assembly.

Polygons#

polygon(V) is exported. signed_distance, polygon_spaces and lift are public and not exported; using Bramble: polygon_spaces, lift brings the last two in by name. A polygon is a marker value: :P => polygon(V) in a domain labels the nodes of a 2D mesh :P (interior), :P_boundary and :P_exterior. The vertices are validated with exact predicates for orientation, folding back and crossing: at least three, no zero-length edge, an area above rounding level, a simple boundary. A vertex in the middle of a straight edge is kept. See Meshes for the grid fitted to a polygon and Grid spaces for polygon_spaces.

Bramble.polygon

source 
polygon(V::AbstractVector{<:NTuple{2, Real}}) -> Polygon{T}

Construct the simple polygon whose boundary visits the vertices V in order and returns from the last to the first. V may run clockwise or counter-clockwise; the result is stored counter-clockwise. Coordinates are converted to the promoted floating-point type T.

A vertex in the middle of a straight edge is kept as a vertex.

The area is zero up to rounding when |2A| ≤ 8nεL², with 2A the shoelace sum, n the vertex count, ε the epsilon of the coordinate type and L the larger side of the bounding box.

Throws

  • ArgumentError: if V has fewer than three vertices, a coordinate is not finite, two consecutive vertices coincide (the last and the first included), the polygon has zero area up to rounding, or its boundary crosses or touches itself (a bowtie, an edge folding back on the previous one).

Bramble.signed_distance

source 
signed_distance(P::Polygon, x) -> Real

Signed Euclidean distance from the point x = (x₁, x₂) to the boundary of P: negative inside, zero on the boundary, positive outside.

The distance is the minimum over the edges of the exact distance from x to the edge; the sign comes from the crossing number of a horizontal ray from x, so non-convex polygons and reflex vertices are handled.

Level sets#

levelset(φ) is exported. It wraps a function φ(x) as a 2D marker value, distinct from a predicate: :D => levelset(φ) in a domain labels the nodes of a 2D mesh :D (where φ < 0), :D_boundary (on the curve φ = 0) and :D_exterior (where φ > 0). φ must return a real number, not a Bool, and need not be a signed distance. The labels follow the rules of a polygon's: a 2D set, no reserved label, no clash with another marker's labels. With a time_set, φ still takes x alone.

Bramble.levelset

source 
levelset(φ) -> LevelSet

Wrap the function φ(x), x = (x₁, x₂), as a 2D level-set marker. In a domain, :D => levelset(φ) gives a 2D mesh the labels D (nodes where φ < 0), D_boundary (nodes on the curve φ = 0) and D_exterior (nodes where φ > 0).

φ must return a real number, not a Bool. It need not be a signed distance; a mesh samples each grid line at 129 points and bisects every sign change, so φ only has to change sign across the curve. Two roots on a line closer than its sample spacing are missed. With a time_set, φ still takes x alone.

Examples

using Bramble
L = levelset(p -> hypot(p[1], p[2]) - 1)
Ω = domain(interval(-1.25, 1.25) × interval(-1.25, 1.25), :D => L)
labels(Ω)

# output
(:D, :D_boundary, :D_exterior)
