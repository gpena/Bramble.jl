Heat equation#

The first time-dependent problem in this manual. Space is discretised exactly as in the linear Poisson example; time is left continuous and handed to a stepper from the SciML stack.

Problem#

\[\partial_t u = \Delta u + f \text{ in } \Omega \times (0, T], \qquad u = g \text{ on } \texttt{left}, \qquad u + \partial_n u = h \text{ on } \texttt{right}, \qquad u(\cdot, 0) = u_0,\]

on \(\Omega = (0,1)\) with \(\partial_n\) the outward normal derivative, and the manufactured solution \(u_{\text{exact}}(x, t) = e^{-t} \sin(\pi x)\), which forces

\[f(x, t) = (\pi^2 - 1)\, e^{-t} \sin(\pi x),\]

vanishes at the left end, so \(g = 0\), and gives the Robin data \(h(x, t) = u_{\text{exact}} + \partial_x u_{\text{exact}} = e^{-t} (\sin(\pi x) + \pi \cos(\pi x))\) at the right end. Later sections also use the same solution with a Dirichlet condition at both ends, since it vanishes at both.

The method of lines#

Discretising space alone leaves one ordinary differential equation per degree of freedom,

\[M \frac{\mathrm{d} u_h}{\mathrm{d} t} = F(t) - A u_h,\]

where \(A\) is the same discrete Laplacian the steady problem assembles, \(F(t)\) is the source at time \(t\), and \(M\) is the mass matrix of the discrete inner product \(\langle \cdot, \cdot \rangle_h\). It is diagonal, since that inner product is a weighted sum over grid points.

Boundary relations through ghost points#

semidiscretize builds exactly this. The Robin end goes through the ghost layer, as in the Neumann and Robin Poisson example: gridspace(Ωₕ; ghosts) adds a ghost point beyond the end, and constrained takes a function of the trial function u that returns one side => relation => data entry per side. The data may take the time as a second argument, (x, t) -> ..., which semidiscretize finds by the arity and refreshes at every step. The Dirichlet end is the relation u => g, which removes its node from the unknowns. The spatial form is written \(\langle -\Delta_h u, v \rangle_h\), which reads the ghost values the relations fix:

using Bramble
using Bramble: mass_matrix
using OrdinaryDiffEqBDF

uexact(x, t) = exp(-t) * sinpi(x[1])
source(x, t) = (pi^2 - 1) * exp(-t) * sinpi(x[1])
robin(x, t) = exp(-t) * (sinpi(x[1]) + pi * cospi(x[1]))

Ω = domain(interval(0.0, 1.0), :left => :left, :right => :right)
Ωₕ = mesh(Ω, 101)
Wₕ = gridspace(Ωₕ)
I = interval(0.0, 1.0)          # the time domain

function robin_problem(Ωₕ, (left, right); T = 1.0)
    Cₕ = constrained(gridspace(Ωₕ; ghosts = right),
        u -> (left => u => (x, t) -> 0.0, right => u + ∂ₙ(u) => robin))
    fₕ = element(Bramble.padded_space(Cₕ), 0.0)
    a = form(Cₕ, Cₕ, (u, v) -> innerₕ(-1.0 * Δₕ(u), v))
    l = form(Cₕ, v -> innerₕ(fₕ, v))
    sd = semidiscretize(a, l; update_coefficients! = t -> Rₕ!(fₕ, x -> source(x, t)))
    u₀ = parent(Rₕ(gridspace(Ωₕ), x -> uexact(x, 0.0)))[2:end]   # the left node is no unknown
    sol = solve(ode_problem(sd, u₀, (0.0, T)), FBDF(); reltol = 1e-10, abstol = 1e-12)
    return Cₕ, sd, sol
end

Cₕ, sd_robin, sol_robin = robin_problem(Ωₕ, (:left, :right))

update_coefficients! is called with the current time just before each assembly, and a time-dependent source goes there. Rₕ! writes into the grid function fₕ that the form already references, so nothing is rebuilt. fₕ lives on the padded space because the ghost space has no Rₕ! of its own. The initial condition holds the 100 unknowns, the grid points except the eliminated left node.

Eliminated nodes in the mass matrix#

The Dirichlet node is no unknown and the Robin relation fixes only the ghost, so no row of the system is algebraic. mass_matrix is the diagonal of grid weights on the remaining 100 nodes, and the system is an ordinary differential equation:

M_robin = mass_matrix(sd_robin)
(size(M_robin), M_robin[1, 1], M_robin[100, 100])   # first interior node, Robin end
((100, 100), 0.01, 0.0050000000000000044)

The solution at the final time#

Bramble.lift(Cₕ, u, t) returns the padded-grid values of the unknowns u with the ghost value and the eliminated node filled in from the relations at time \(t\). The ghost lies beyond the right end, so the physical nodes are its first 101 entries:

using Bramble: lift

Uₚ = parent(lift(Cₕ, sol_robin.u[end], 1.0))
uₕ_robin = element(Wₕ)
parent(uₕ_robin) .= Uₚ[1:101]
normₕ(Rₕ(Wₕ, x -> uexact(x, 1.0)) - uₕ_robin)
1.868087231114406e-5

The whole time evolution fits in one surface, x and t the two horizontal axes and u as height and colour. It needs no new solve: sol_robin interpolates continuously in t, so sampling it on a uniform grid of times and lifting each sample is enough. The red curve traces u(x, t) at the current instant and loops on its own, shrinking as the solution decays:

ts = range(0.0, 1.0; length = 60)
Z = reduce(vcat, (parent(lift(Cₕ, sol_robin(t), t))[1:101]' for t in ts))
spacetime_surface_plot(points(Ωₕ), collect(ts), Z; title = "Heat equation, x-t-u")

The relation is satisfied by the ghost, so the check that means something is one-sided and independent of it: the three-point backward difference of the lifted solution at the Robin end, with the actual spacings, must satisfy \(u + \partial_n u = h\) up to its truncation error, of order \(h^2\):

function robin_residual(Ωₕ, Cₕ, sol)
    U = parent(lift(Cₕ, sol.u[end], 1.0))
    xs = collect(points(Ωₕ))
    n = length(xs)
    h₁, h₂ = xs[n] - xs[n - 1], xs[n - 1] - xs[n - 2]
    dₙ = (2h₁ + h₂) / (h₁ * (h₁ + h₂)) * U[n] - (h₁ + h₂) / (h₁ * h₂) * U[n - 1] +
         h₁ / (h₂ * (h₁ + h₂)) * U[n - 2]
    return abs(U[n] + dₙ - robin(xs[n], 1.0))
end

robin_residual(Ωₕ, Cₕ, sol_robin)
0.0005702418304793788

Dirichlet conditions as algebraic constraints#

The dirichlet keyword of semidiscretize belongs to a plain space; a ghost space refuses it, and takes the relation u => g instead. The sections below need what the ghost path does not offer yet, so they keep a plain space and a Dirichlet condition at both ends, which the manufactured solution satisfies with \(g = 0\). The time domain passed to dirichlet_constraints lets the boundary values be written as g(x, t). The spatial form is the one the steady problem writes, so the steady state of the system solves \(A u_h = F\):

fₕ = element(Wₕ, 0.0)
a = form(Wₕ, Wₕ, (u, v) -> inner₊(∇ₕ(u), ∇ₕ(v)))
l = form(Wₕ, v -> innerₕ(fₕ, v))

bcs = dirichlet_constraints(Ωₕ, I, :boundary => (x, t) -> 0.0)

sd = semidiscretize(a, l;
    dirichlet = bcs,
    update_coefficients! = t -> Rₕ!(fₕ, x -> source(x, t)))
Semidiscretization {M uₕ' = F(t) - A uₕ}:
  Space: ScalarGridSpace{1D, Float64, 101 dofs}
  Operator: 101×101, 301 stored
  Constraints: g(x, t) on :boundary
  Reassembled: once

Here the constrained row of A is \(e_k\) and the matching entry of F(t) is \(g(x_i, t)\), which is what assemble produces for the steady problem too. mass_matrix zeroes those same rows, so each one reads

\[0 = g(x_i, t) - u_h[i],\]

the boundary condition itself. The system is therefore a differential-algebraic one, and needs only \(g\), never \(\partial_t g\), which prescribing \(u_h'\) on the boundary would have required:

M = mass_matrix(sd)
(M[1, 1], M[51, 51], M[101, 101])   # boundary, interior, boundary
(0.0, 0.010000000000000009, 0.0)

Solving with a BDF stepper#

ode_problem wraps the semidiscretisation, its mass matrix, and its exact Jacobian \(-A\) into a problem OrdinaryDiffEq can step. Because the mass matrix is singular, the method has to be one that admits that: FBDF and QNDF here, or a Rosenbrock method such as Rodas5P:

prob = ode_problem(sd, Rₕ(Wₕ, x -> uexact(x, 0.0)), I)
sol = solve(prob, FBDF(); reltol = 1e-10, abstol = 1e-12)

uₕ = element(Wₕ)
parent(uₕ) .= sol.u[end]
normₕ(Rₕ(Wₕ, x -> uexact(x, 1.0)) - uₕ)
2.3805047580463986e-5

The initial condition is copied, never mutated, and the copy is made consistent with the algebraic rows at \(t_0\) before stepping.

sol also exports as a ParaView time series; see Plot or export a grid function.

Rosenbrock methods and time-dependent sources

Rodas5P and friends also want the time derivative of the right-hand side, which they build by differentiating through t. An update_coefficients! hook writing into a Float64 grid function, as the one above does, cannot accept a ForwardDiff.Dual time, so pass Rodas5P(autodiff = AutoFiniteDiff()) from ADTypes, use a BDF method (which needs no ∂f/∂t at all), or supply an analytical tgrad, as the time stepping example does.

Convergence under refinement#

Refining the mesh while holding the time tolerance far below the spatial error isolates the spatial error. The uniform mesh above would flatter the rate: on it \(\sin(\pi x)\) is an exact discrete eigenmode of the Laplacian, a special case that says little about the scheme. The series therefore runs on one seeded random coarse mesh, refined in place with iterative_refinement! so every finer level is the same random mesh, dyadically split. The domain carries no :left or :right marker, which the one-argument iterative_refinement! would refuse to drop. The uniform mesh stays above, where the check on the mass matrix needs a known grid weight \(h\):

using Random

function heat_series(levels; n0 = 11)
    Random.seed!(20260903)
    Ωs = domain(interval(0.0, 1.0))
    Ωc = mesh(Ωs, n0, false)
    hs, errs = Float64[], Float64[]
    for level in 1:levels
        Wc = gridspace(Ωc)
        fc = element(Wc, 0.0)
        ac = form(Wc, Wc, (u, v) -> inner₊(∇ₕ(u), ∇ₕ(v)))
        lc = form(Wc, v -> innerₕ(fc, v))
        bc = dirichlet_constraints(Ωc, I, :boundary => (x, t) -> 0.0)

        sdc = semidiscretize(ac, lc;
            dirichlet = bc,
            update_coefficients! = t -> Rₕ!(fc, x -> source(x, t)))

        solc = solve(ode_problem(sdc, Rₕ(Wc, x -> uexact(x, 0.0)), I),
            FBDF(); reltol = 1e-11, abstol = 1e-13)

        uc = element(Wc)
        parent(uc) .= solc.u[end]
        push!(hs, hₘₐₓ(Ωc))
        push!(errs, normₕ(Rₕ(Wc, x -> uexact(x, 1.0)) - uc))
        level < levels && iterative_refinement!(Ωc)
    end
    return hs, errs
end

The Robin problem runs on the same seeded random mesh through robin_problem, whose sides here are the :xmin and :xmax of a domain with no markers of its own. Its error is the one at the physical nodes of the lifted solution, and the residual of the Robin relation, as above, comes with it:

function robin_series(levels; n0 = 11)
    Random.seed!(20260903)
    Ωc = mesh(domain(interval(0.0, 1.0)), n0, false)
    hs, errs, resids = Float64[], Float64[], Float64[]
    for level in 1:levels
        Cc, _, solc = robin_problem(Ωc, (:xmin, :xmax))
        Wc = gridspace(Ωc)
        uc = element(Wc)
        parent(uc) .= parent(lift(Cc, solc.u[end], 1.0))[1:length(parent(uc))]
        push!(hs, hₘₐₓ(Ωc))
        push!(errs, normₕ(Rₕ(Wc, x -> uexact(x, 1.0)) - uc))
        push!(resids, robin_residual(Ωc, Cc, solc))
        level < levels && iterative_refinement!(Ωc)
    end
    return hs, errs, resids
end

Time-dependent boundary data#

The Dirichlet data above do not depend on time, since the manufactured solution vanishes on \(\partial\Omega\). Driving the problem entirely from the boundary puts (x, t) in a Dirichlet condition: start at zero and raise the left end linearly, with the right end held fixed. The two ends are named on the domain above; a bare domain(interval(...)) registers only :boundary and :interior, so there would be no :left to constrain.

gₕ = element(Wₕ, 0.0)
l_drive = form(Wₕ, v -> innerₕ(gₕ, v))
bcs_drive = dirichlet_constraints(Ωₕ, I,
    :left => (x, t) -> t,
    :right => (x, t) -> 0.0)

sd_drive = semidiscretize(a, l_drive; dirichlet = bcs_drive)
sol_drive = solve(ode_problem(sd_drive, element(Wₕ, 0.0), I), FBDF();
    reltol = 1e-10, abstol = 1e-12)

u_end = sol_drive.u[end]
(u_end[1], u_end[51], u_end[101])
(1.0, 0.43750333901043964, 0.0)

The surface shows the ramp and the lag. The left edge rises along the line \(u = t\) and the right edge stays at zero. The interior follows with a delay, and the red profile never reaches the straight line between the two ends:

Z_drive = reduce(vcat, (sol_drive(t)' for t in ts))
spacetime_surface_plot(points(Ωₕ), collect(ts), Z_drive; title = "Boundary-driven heat equation, x-t-u")

At \(t = 1\) the ends hold the prescribed \(g\) to solver tolerance: one and zero. The interior is climbing towards the straight line \(1 - x\) that the source-free steady problem gives, but has not arrived, with \(0.44\) at the midpoint against the steady \(0.5\). The left end was still moving over the whole interval, so diffusion is chasing a boundary value that never settled.
