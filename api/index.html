Utilities

Linear Algebra Backends

Bramble.backend — Function
backend(; vector_type, matrix_type)

Creates a linear algebra Backend using keyword arguments.

Defaults to standard dense Float64 vectors and SparseMatrixCSC matrices:

  • vector_type = Vector{Float64}

  • matrix_type = SparseMatrixCSC{Float64,Int}

Examples

julia> dense_sparse = backend() # Default backend (Dense-Sparse Float64)

julia> using SparseArrays;
       SVec{T} = SparseVector{T,Int};
       SMat{T} = SparseMatrixCSC{T,Int};
       T64 = Float64;

julia> sparse_sparse = backend(vector_type = SVec{T64}, matrix_type = SMat{T64})

julia> T32 = Float32;
       dense32 = backend(vector_type = Vector{T32}, matrix_type = SMat{T32})

Function Embedding

Bramble.BrambleFunction — Type
struct BrambleFunction{ArgsType, hastime, CoType, DType}

Internal structure wrapping user-defined functions for type-agnostic, zero-overhead dispatch. Uses FunctionWrappers.FunctionWrapper to provide stable, compiled calling signatures.

Fields

  • wrapped: A FunctionWrapper wrapper for the function

  • domain: Domain of the function (typically a CartesianProduct or Domain)

source

Embeds a Julia function into a BrambleFunction defined over space_domain (and optional time_domain).

source
Bramble.has_time — Function
has_time(_)

Checks if a BrambleFunction is time-dependent by inspecting its hastime type parameter. Returns true if time-dependent, false otherwise.

Constructs a 1-dimensional CartesianProduct representing the closed interval $[x, y]$. Inputs are converted to floating-point numbers.

Bramble.point — Function
point(x)

Creates a collapsed 1D CartesianProduct representing the point $[x, x]$.

source
Bramble.box — Function
box(a, b)

Creates a CartesianProduct from two points a and b, defining opposite corners of the bounding box. Intervals are constructed as $[\min(a_i, b_i), \max(a_i, b_i)]$.

source
Bramble.cartesian_product — Function
cartesian_product(x, y)

Returns a CartesianProduct from coordinates or intervals.

  • If two scalar values x and y are provided, returns a 1D CartesianProduct representing $[x, y]$.
  • If an NTuple{D, Tuple{T,T}} is provided, returns a D-dimensional CartesianProduct.
source
Bramble.:× — Function

Computes the tensor product of two CartesianProducts X and Y. The resulting dimension is dim(X) + dim(Y) with promoted element type.

Bramble.get_boundary_symbols — Function

Returns a tuple of default boundary symbols for a CartesianProduct or Domain.

  • 2D $[x_1, x_2] \times [y_1, y_2]$: (:bottom, :top, :left, :right)

Markers and Domains

Bramble.@markers — Macro

Convenience macro for constructing a DomainMarkers instance.

source
Bramble.markers — Function
markers(space_set, pairs)

Constructs a DomainMarkers object from a series of label => identifier pairs.

The identifier can be a Symbol, a Tuple of Symbols, or a Function.

Example

julia> I = cartesian_product(0.0, 1.0);
julia> m = markers(I, :left_boundary => :left, :internal => x -> 0.2 < x < 0.8);
julia> length(m.symbols)
1
julia> length(m.conditions)
1
source
markers(Ω)

Returns the DomainMarkers object associated with the Domain Ω.

source
Bramble.domain — Function
domain(X)

Returns a Domain from a CartesianProduct.

  • domain(X): Assumes a default :boundary marker covering all boundaries of X.
  • domain(X, markers::DomainMarkers): Constructs a domain with explicit markers.
  • domain(X, pairs...): Constructs a domain with markers defined by label-identifier pairs.
  • domain(space_set, time_set, pairs...): Constructs a spatio-temporal domain.
